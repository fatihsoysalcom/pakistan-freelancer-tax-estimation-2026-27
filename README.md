# Pakistan Freelancer Tax Estimation 2026-27

This Python script demonstrates how to estimate income tax for Pakistani freelancers for the 2026-27 fiscal year. It uses hypothetical progressive tax slabs and rates to calculate the tax liability based on user-provided annual income. The example illustrates the core concept of tax estimation and progressive taxation mentioned in the article.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Enter your estimated annual income when prompted.
